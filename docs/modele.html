Squelette et animations d'autres fichiers

Les animations sont reciblées sur les os du modèle (appariés par nom : Mixamo, Bip01, Blender…). Elles rejoignent la liste « Animation » et « Générer toutes les animations ».

Bibliothèque d'animations (CC0)

Animations libres de droits, déjà prêtes : choisis-en une ou plusieurs, elles sont reciblées sur le squelette du modèle (il faut donc un modèle avec squelette). Pas besoin d'ouvrir de fichier.

Garde-robe : cheveux, armes, vêtements, chaussures, accessoires

Pièces libres de droits (CC0 : Quaternius, KayKit). Les accessoires se fixent à un os et suivent les animations ; les vêtements et cheveux sont ajustés au squelette du modèle (proportions humaines).

Stockage permanent de la banque (GitHub, gratuit)

Sans ça, la banque reste dans ce navigateur seulement. Avec un dépôt GitHub dédié, tes personnages et vêtements sont conservés, versionnés et disponibles sur tous tes appareils. Lecture sans identifiant si le dépôt est public ; l'écriture demande un jeton limité à ce seul dépôt, gardé dans ce navigateur uniquement.

/
Comment créer le dépôt et le jeton (2 minutes)
  1. github.com → New repository → nom character-forge-bank, Public, coche « Add a README ».
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate : « Only select repositories » → ce dépôt ; Permissions → Repository → Contents : Read and write.
  3. Colle le jeton ci-dessus, coche « activer », clique « Tester ».

À savoir

  • Pas d'animation dans le fichier ? Seule la pose est rendue. Meshy propose un rig et des animations : télécharge le GLB animé. Sinon, la carte « Squelette et animations d'autres fichiers » ajoute un squelette (FBX Mixamo…) puis des animations venues d'autres fichiers (Mixamo, bibliothèques).
  • FBX : seules les textures incluses dans le fichier sont lues.
  • Les bras et jambes qui se confondent avec le corps sont assombris à la frontière (option cochée).
