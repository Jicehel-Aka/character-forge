Détourage

Détourage simple par couleur de fond (bords de l'image). Pour un détourage IA, utilise la commande extract --segment puis ouvre le cutout.png ici : l'alpha est conservé.

Ctrl+Z / Ctrl+Y — chaque trait, zone ou détourage s'annule.
auto (4 coins)

Choisis l'outil pipette puis clique sur la couleur à enlever (fond, bulle, trame…) : on peut enchaîner plusieurs couleurs, sans toucher au reste.

Détourage intelligent

Outil colorier à garder : barbouille le personnage (quelques traits dans chaque partie : peau, vêtements, cheveux). Sans trait « à enlever », les bords de l'image servent de fond. Ajoute des traits à enlever là où ça déborde (bulle, décor collé), puis lance. L'algorithme suit les contours noirs du dessin.

Tracé : dessine librement un contour autour d'une zone, relâche : l'intérieur est effacé (ou seul l'intérieur est gardé). Tout s'annule avec ↶.

Découper une vue

Image avec plusieurs poses : outil garder une zone, trace un rectangle autour d'une pose ; elle devient une nouvelle vue (l'image d'origine reste intacte).
